# NovaTB

## Descripción

NovaTB es una aplicación web de comercio electrónico desarrollada como proyecto de portafolio durante mi formación en Ingeniería de Software.

El proyecto fue creado con el propósito de poner en práctica conocimientos de desarrollo frontend, backend, bases de datos y arquitectura de software, integrando estas áreas en una aplicación completa.

Más allá de desarrollar funcionalidades, NovaTB representó una oportunidad para aprender a visualizar un sistema de software de manera más amplia, comprendiendo cómo sus diferentes componentes se relacionan y cómo organizar un proyecto de forma estructurada y mantenible.

## Tecnologías

### Frontend
- React
- Vite
- Axios
- CSS

### Backend
- Node.js

### Base de datos
- MySQL

### Herramientas
- Git

- Cloudinary

## Arquitectura

El backend de NovaTB está organizado mediante una arquitectura en capas, separando las responsabilidades principales de la aplicación.

La estructura incluye:

- Routes
- Controllers
- Services
- Models
- Middleware
- Configuration

Esta organización me permitió comprender mejor cómo estructurar un proyecto de software, separar responsabilidades y facilitar el mantenimiento y evolución de la aplicación.

## Funcionalidades

- Registro de usuarios
- Inicio de sesión
- Visualización de productos
- Consulta de productos
- Búsqueda de productos
- Categorías
- Carrito de compras
- Gestión de productos
- Gestión de pedidos
- Autenticación y control de acceso

## Aprendizajes

El desarrollo de NovaTB me permitió fortalecer mis conocimientos en diferentes áreas del desarrollo de software.

Durante el proyecto aprendí a:

- Diseñar y organizar la estructura de un proyecto de software.
- Comprender y aplicar una arquitectura en capas.
- Desarrollar una API utilizando Node.js y Express.
- Diseñar y trabajar con una base de datos MySQL.
- Integrar frontend, backend y base de datos en una misma aplicación.
- Comprender mejor la comunicación entre las diferentes partes de un sistema.
- Organizar responsabilidades dentro del backend.
- Pensar en un software desde una perspectiva más amplia, no solamente desde la implementación de funcionalidades.

Uno de los principales aprendizajes del proyecto fue comprender que desarrollar software no consiste únicamente en escribir código, sino también en tomar decisiones sobre arquitectura, organización, comunicación entre componentes, datos y mantenimiento del sistema.

Durante el desarrollo también descubrí que tengo una mayor afinidad por el área de backend, especialmente por la lógica de negocio, la organización de la aplicación, las APIs y la interacción con las bases de datos.
